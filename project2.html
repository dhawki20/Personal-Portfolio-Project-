Predicting MLB World Series Winners

Research question: How accurately can an MLB playoff team's regular-season win percentage and performance statistics predict whether it will win the World Series, using data from the 2005–2024 MLB seasons?

Problem and data

This is a binary-classification project. The target, world_series_winner, equals 1 for the champion and 0 for every other playoff team. Each row represents one playoff team in one season.

The data come from the Teams table in Sean Lahman's Baseball Database. The selected features are win percentage, run differential per game, runs per game, OPS, home runs per game, stolen bases per game, ERA, and WHIP.

Open the cleaned modeling dataset.

Preparation and modeling

I removed duplicate team-season records, filtered to playoff teams, created comparable rate statistics, calculated OPS and WHIP, and excluded postseason results from the predictors to avoid data leakage.

The chronological split trains on 2005–2019 and tests on 2020–2024. I compared a best-win-percentage baseline with logistic regression and random forest classification.

Results and interpretation

Baseline

Correctly selected 2 of 5 holdout champions.

Logistic regression

Selected 1 of 5 and produced the best ROC-AUC at 0.691.

Random forest

Selected 0 of 5 champions in the holdout seasons.

The main conclusion is that regular-season strength contains useful signal, but added model complexity did not outperform the simple best-record baseline when selecting one champion per season.

Limitations and ethics

  • Twenty seasons contain only 20 champions, creating a small and imbalanced positive class.
  • The shortened 2020 season and changing playoff formats limit comparability.
  • Regular-season totals omit injuries, roster changes, playoff matchups, and starting-pitcher availability.
  • The results show associations, not causes, and should not be used as gambling advice.
